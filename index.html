    Tags de Estilização de texto

  • p é a tag paragraph, onde se pula uma linha de parágrafo.
  • mark é a tag de marca-texto, destacando texto.
  • small é a tag que faz o texto ficar menor.
  • itálico tag que converte o texto para formatação em itálico.
  • underline sublinhado, texto sublinhado.
  • strong strong, adiciona o negrito no texto, durante texto para fala, adiciona enfase.
  • sub sub, adiciona um texto abaixo da linha.
  • sup sup, adiciona um texto acima da linha.
  • Blockquote, faz o texto virar uma citação.

  • Tag Font, troca a fonte, exemplo verdana

  • Del del ou strikethrough, adiciona um efeito de riscado / removido do texto

  • Abbr É uma abreviação de texto.
